## [v1.9.6] - 2026-07-02 - 💧 - AESTHETICS - 水的型態呼應圳水主題：有方向的流、蜿蜒的水脈軌跡
1. **圳道水脈線**：新增三條蜿蜒穿行畫面的虛線水路，以 `stroke-dashoffset` 動畫緩緩前行——潛流在城市街道之下、不曾消失的瑠公圳軌跡，與「以水文地景為經緯」的主題文案相互呼應。
2. **流光取代閃爍**：光斑由原地明滅改為順流滑行漸隱（`streak-drift`），18 道光痕沿一致方向前進——渠道裡的活水有方向、有力量，不同於海面的漫射波光。
3. **波形平緩化與流速提升**：三層波改為週期長、波幅小的流暢曲線（水順著微幅地勢起伏），流速由 16–24 秒縮短至 11–18 秒且統一流向，展現圳水的力量感。
4. **稻浪意象**：底部波帶疊入一層淡黃綠（`rgba(217,240,196,0.30)`），呼應圳水穿梭於台北盆地稻浪間的歷史地景。
5. **清澈感**：水面流紋改為橫向拉長的流線形光斑並統一漂移方向，減少模糊半徑，整體更透亮。

## [v1.9.5] - 2026-07-02 - 🌊 - AESTHETICS - 首頁水波真實感升級：碎波光、水下光網與波浪起伏
1. **碎波光（glint）**：以 22 個橫向細碎光斑取代原本的大橢圓光暈，各自不同節奏地明滅與橫向拉伸，模擬陽光在波峰碎裂的「碎銀」反光——這是真實水面最具辨識度的視覺特徵。
2. **水下光網（caustics）**：新增兩層以 CSS radial-gradient 生成的光斑網，以不同速度、方向對角漂移並以 soft-light 混合，重現水底光影緩慢流動的質感，位移量對齊圖樣週期實現無縫循環。
3. **波浪升級**：三層波改用多諧波不規則路徑（起伏更自然）、浪尖加白色高光描邊，並疊加 `wave-bob` 上下浮動動畫，水平流動＋垂直起伏的複合運動更接近真實水面。
4. **零載入負擔**：全部效果以純 CSS transform/opacity 動畫實現（GPU 合成、不觸發重排），無圖片、無外部函式庫、無 JS 動畫迴圈，首頁載入速度不受影響；並支援 `prefers-reduced-motion` 自動停用動畫。
5. **修復 Hydration 警告**：碎波光座標改用確定性偽隨機生成並固定兩位小數精度，消除 SSR 與瀏覽器端浮點數序列化差異造成的 hydration mismatch。
